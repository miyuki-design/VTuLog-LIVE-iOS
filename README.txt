VTuLog LIVE / Live2D表情連動テスト版

GitHubの VTuLog-LIVE-iOS/src/ の同名ファイルを2つとも丸ごと差し替え、Commit changes後にActionsで再ビルドしてください。

1. Live2Dモデルを読み込む（再起動時の自動復元でも可）
2. 前後カメラ同時起動テスト
3. 顔認識・表情数値テスト
4. Live2D表情反映テスト
5. 口・笑顔・まばたきでアバターの表情が動くか確認

表情反映を停止しても顔解析とカメラは動きます。前面映像は表示・保存・送信しません。
